# 09 · 双端适配：macOS 已实测，Windows 待验证

> 本文档回答：项目在 macOS/Windows 两端的兼容现状、风险点、适配方案。
> 核心结论：**代码层跨平台条件已具备，剩余为配置与视觉适配；未经实测前不宣称已支持 Windows**（诚实标注）。

---

## 1. 兼容现状（截至编写时）

| 维度 | macOS | Windows |
|------|-------|---------|
| 运行验证 | ✅ 已实测（日常使用） | ⚠️ 未验证（尚无 Windows 测试环境） |
| 桌面容器 | Electron 成熟支持 | Electron 成熟支持 |
| 透明窗口 | ✅ 已实现 | 技术可行，未实测 |
| 原生菜单 | ✅ 系统级毛玻璃 | 技术可行（Win 风格不同） |
| 托盘 | ✅ 菜单栏图标 | 技术可行（系统托盘） |
| 精灵表渲染 | ✅ PixiJS WebGL | 跨平台引擎，应无差异 |

---

## 2. 已具备的跨平台条件（代码层）

| 项 | 实现 | 说明 |
|----|------|------|
| 路径 | 全用 `path.join` | 无硬编码分隔符 |
| 用户数据 | `~/.petpet` 映射 | Windows 自动映射到用户目录 |
| 字体 | CSS 含微软雅黑 fallback | 中文显示双端可用 |
| 动画引擎 | PixiJS WebGL | 双端一致 |

---

## 3. 风险点清单（诚实标注）

| 风险点 | 性质 | 严重度 | 处理方案 |
|--------|------|--------|---------|
| Windows 透明窗口不支持 CSS backdrop-filter 毛玻璃 | 视觉降级，**非功能缺失** | 中 | 透明窗口降级为半透明/实色底 |
| electron-builder 未配置 win 打包目标 | 配置缺失 | 高（阻断打包） | 补 win 目标配置（nsis 安装包） |
| build.files 漏 panel 文件 | 配置缺失 | 高（面板白屏） | 补 `panel/**` 进 build.files |
| macOS 专属 API（app.dock.setIcon） | 平台差异 | 低 | 已有 darwin 平台防护 |
| 字体差异（苹方 vs 微软雅黑） | 视觉差异 | 低 | fallback 已配 |

---

## 4. 验证方案（按成本排序）

### A. 真机 dev 运行（推荐，半小时）
```
在有 Windows 的机器上：npm install && npm run dev
```
- 成本：半小时（环境 + 冒烟）
- 真实度：最高（真实渲染、真实托盘、真实透明窗口）
- 前置：补齐 §3 两个配置缺失项

### B. CI 自动构建冒烟（GitHub Actions）
- Windows runner 自动 build + 启动冒烟
- 成本：一次性配置
- 真实度：中（能验证构建，透明窗口/托盘需人工）

### C. 虚拟机（成本最高）
- 不推荐：Electron 透明窗口在 VM 里的 GPU 支持是坑

**推荐 A + B 组合**：A 验证真实效果，B 防止回归。

---

## 5. 双端差异清单（适配预期）

| 差异 | macOS | Windows | 适配策略 |
|------|-------|---------|---------|
| 菜单风格 | 系统毛玻璃 | Win11 风格 | 原生 Menu 自动跟随系统 |
| 托盘位置 | 菜单栏（顶） | 系统托盘（右下） | Electron 自动处理 |
| 窗口圆角 | 系统圆角 | 方形窗口 | 视觉差异接受 |
| 字体渲染 | 苹方/平滑 | 微软雅黑 | fallback 已配 |
