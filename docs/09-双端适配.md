## 4. 验证记录（真机实测）

### ✅ Windows（红苕爸爸 Win11，2026-08-09 21:29）

- **结果**：Windows 技术闭环打通（能装能跑、无崩溃）——Publish v1.1.0 前置条件满足
- **暴露 3 层问题（均已修）**：① 引导缺陷（Win+R 打开不存在路径报错）② 主进程不自动创建 `~/.petpet/pets` 目录（P0 代码缺陷）③ 报错文案 `~` 对 Windows 用户不友好
- **修复**：0f2dfc9（目录自动创建 + 按平台显示文案）

### 验证方案（供后续回归参考）

- **A. 真机 dev 运行**：在有 Windows 的机器上 `npm install && npm run dev`（红苕爸爸实测即此路径，真实渲染/托盘/透明窗口均已覆盖）
- **B. CI 自动构建冒烟**：Windows runner 自动 build + 出包（已启用，防回归）
- C. 虚拟机：不推荐（Electron 透明窗口在 VM 里的 GPU 支持是坑）
