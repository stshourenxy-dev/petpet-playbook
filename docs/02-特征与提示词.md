# 02 · 特征与提示词：把一只狗翻译成机器听得懂的话

> 本文档回答：画像层的 16 个字段，**如何翻译成 AI 视频生成工具的提示词**。
> 核心结论先行：提示词不是玄学，是**特征的翻译**——结构化的特征输入 + 稳定的模板 = 可控的生成质量。

---

## 1. 提示词五要素结构

一条可用的动作提示词 = 五个要素，缺一不可：

```
① 形象锚定  「保持 @图片1 这只皮克斯3D卡通风格的棕白边牧形象不变，全身完整入镜，包含尾巴」
② 体型约束  「粗壮体型，体长体高比约 1.2:1，腿长比例约 0.6:1」
③ 特征细节  「咖白花色，右侧围脖没开完，嘴筒子有几个麻子」
④ 动作描述  「从趴卧姿态起身伸懒腰：前爪向前伸展→弓背→臀部翘起→张嘴打哈欠→恢复趴卧」
⑤ 画质参数  「动作连贯完整一个循环，节奏舒缓，背景干净纯色」
```

| 要素 | 来源（画像层字段） | 作用 | 优先级 |
|------|-------------------|------|--------|
| ① 形象锚定 | 品种 + 照片 | **防止形象漂移**（最重要的保险丝） | P0 |
| ② 体型约束 | 长宽高比例 + 腿长比 + 体型 | 防止生成错比例（胖狗/腊肠狗） | P0 |
| ③ 特征细节 | 补充说明 | 独特性（围脖、麻子、眼袋） | P1 |
| ④ 动作描述 | 动作需求（人工设计） | 驱动动作内容 | P0 |
| ⑤ 画质参数 | 生成经验（人工配置） | 循环/背景/节奏 | P1 |

## 2. 逐字段翻译规则表

| 画像层字段 | 提示词翻译 | 实例 |
|-----------|-----------|------|
| 品种 | 「皮克斯3D卡通风格的{品种}」 | 「棕白边牧」「柯基」 |
| 长宽高比例 | 「体长体高比约 {长:高}」 | 红苕 1.2:0.4:1 → 「体长体高比约 1.2:1」 |
| 腿长比 | 「腿长比例约 {比}」 | 红苕 0.6:1 → 「腿长比例约 0.6:1」 |
| 体型 | 直接引用离散词 | 「粗壮」「标准」「胖墩」 |
| 补充说明 | 原文直译（去掉口语化） | 「咖白花色，右侧围脖没开完，嘴筒子有几个麻子」 |
| 照片 | 图生视频的 @图片1 参考 | 「保持 @图片1 这只…形象不变」 |
| 年龄态 | 「成年犬体态」/「幼犬」 | 豆豆 2 岁版 → 「2岁犬的幼态特征」 |

**翻译铁律**：

1. **否定词禁用**（拉粑粑 v5 教训）：写「不要尾巴虚化」→ 模型可能反而强化尾巴虚化。动作描述只写**要什么**，不写**不要什么**
2. **动作描述用动词链**：AI 对连续动作的理解强于单动词。用「前爪向前伸展→弓背→臀部翘起→张嘴打哈欠→恢复趴卧」优于「伸懒腰」
3. **幅度词要显式**：AI 默认输出温和动作。「疯狂摇尾巴」实际生成的是钟摆式慢摇（见 §6 教训）——要大幅动作必须叠加「大幅度、快速、身体左右摆动超过30度」类强动作词

## 3. 参考图与参考视频的使用（@图片1 / @视频1）

即梦支持两类参考：

| 参考类型 | 语法 | 用途 | 实例 |
|---------|------|------|------|
| 图片参考 | @图片1 | **形象锚定**（保持宠物形象） | 你自己的设定图（生成锚点） |
| 视频参考 | @视频1 | **动作模仿**（复制参考视频的动作） | 一段你想要宠物做的动作视频 |

**已验证的成功组合**（动作模仿先例）：

```
「@图片1 模仿 @视频1 的动作」= 形象来自图片 + 动作来自视频
```

这是**文生动作失败的兜底方案**：当文字描述动作生成不可靠时（撒娇教训），改用真实/参考视频驱动动作——「模仿 @视频1 的动作，皮克斯3D卡通风格的棕白边牧，趴卧着用前爪环抱…」

**参考图要求**（实测）：
- 正面清晰、光线均匀、背景干净
- 全身入镜（半身图会丢比例约束）
- 设定图风格与目标风格一致（皮克斯3D设定图 → 皮克斯3D生成）

> 参考图质量标准示例（真实照片→设定图的完整流程）见 `01-数据模型.md` §3.6。此处不放示例图——@图片1 指向的应该是**你自己的设定图**，不是本文的任何示例。

## 4. 红苕全量实例（真实使用过的提示词）

### 4.1 撒娇（wiggle）——温柔版（已部署）

```
保持 @图片1 这只皮克斯3D卡通风格的棕白边牧形象不变，全身完整入镜，包含尾巴，
站立姿态，身体兴奋地左右扭动撒娇，尾巴疯狂左右摇摆，
眼睛亮晶晶期待地看着前方，偶尔歪头，嘴角上扬开心，
动作幅度明显、节奏轻快，循环自然，背景干净纯色
```

- 模型：Seedance 2.5（130 积分）
- 实际结果：**温柔版**（歪头+轻扭+钟摆式摇尾，2 秒循环），非疯狂版
- 检查点：①全身含尾巴 ②扭动+摇尾 ③循环衔接 ④形象未变（棕白、白脸纹、白刘海）

### 4.2 伸懒腰（stretch）——动作链完整（已部署）

```
保持 @图片1 这只皮克斯3D卡通风格的棕白边牧形象不变，全身完整入镜，包含尾巴，
从趴卧姿态起身伸懒腰：前爪向前伸展→弓背→臀部翘起→张嘴打哈欠→恢复趴卧，
动作连贯完整一个循环，节奏舒缓，背景干净纯色
```

- 模型：Seedance 2.0（45 积分）
- 实际结果：动作链完整（趴卧→弓背→前伸→哈欠→趴回），一次成功
- 差异点：**动词链描述**（→分隔的连续动作）显著提升动作可识别度

### 4.3 拉粑粑 v5（母版，成功配方参照）

- 模型：Seedance 2.5 + 参考图 + **动作描述不含否定词**
- 教训来源：v1-v4 多次失败后才总结出「不含否定词」配方

---

## 5. 模型与参数（成本实测记录）

| 模型 | 单次成本 | 特点 | 适用 |
|------|---------|------|------|
| Seedance 2.0 | 45 积分 | 性价比高，动作链理解够用 | 动作明确的生成（伸懒腰✅） |
| Seedance 2.5 | 130 积分 | 画质/语义更强，但**不保证幅度** | 复杂动作、高画质需求 |

参数基线（实测）：1280×720、60fps、5 秒、图片参考模式。

**成本红线（血泪教训）**：单动作生成 = 45-130 积分；**每次只生成 1 次，失败立即止损**，不连续重试。重试前必须改提示词或换模型——同样提示词重试 5 次 = 重复烧钱。

---

## 6. 失败教训库（比成功配方更值钱）

| 教训 | 现象 | 根因 | 对策 |
|------|------|------|------|
| **幅度失控** | 2.5 模型出「疯狂摇尾巴」= 钟摆式慢摇 | AI 默认输出温和动作，语义对幅度词不敏感 | 强动作词叠加（大幅度/快速/超过30度）；或换视频参考驱动 |
| **否定词反噬** | 写「不要XX」→ 反而强化 XX | 模型对否定结构理解差 | 只写要什么（拉粑粑 v5 配方） |
| **单动词贫瘠** | 「伸懒腰」单动词 → 动作不完整 | 动作链信息不足 | 动词链描述（→分隔） |
| **形象漂移** | 生成像别的狗 | 缺形象锚定 | @图片1 + 「保持…形象不变，全身完整入镜」 |

---

## 7. 风格迁移注意点（换风格必读）

本文档的模板锚定皮克斯 3D 风格。换风格时只需改**要素①**（形象锚定）：

| 目标风格 | 要素①改法 | 风险 |
|---------|-----------|------|
| 写实 | 「写实风格的{品种}照片级渲染」 | 比例约束更难传达，建议放弃夸张比例 |
| 2D 动漫 | 「吉卜力/新海诚风格」 | 需重选参考图风格 |
| 像素风 | 「像素艺术风格」 | 精灵表管线不变，分辨率要求降低 |

其余四要素（体型/特征/动作/画质）风格无关，可复用。

---

## 8. 本文档可自行修改的点

1. **改模板骨架**：五要素结构是通用的，按自己工具（即梦/可灵/其他）的语法微调
2. **补动作库**：每个新动作 = 一条动词链描述 + 一组检查点（参考 §4 格式）
3. **调成本策略**：模型选择取决于你的预算和工具定价
4. **换参考策略**：有真实宠物视频 → 优先 @视频1 动作模仿（成功率更高）

## 9. 实证案例：叮当（柯基）idle 成功 Prompt（2026-08-11）

> 来源：叮当待机动画生成战役。即梦 v1-v6 六轮失败后，用户 23:00 亲自调整出这条 prompt，一次成功（断尾✓ 单头玩具✓ 本体8/10✓），是当前唯一三项全过的版本。

### 9.1 成功 Prompt 全文

```
皮克斯3D动画风格。柯基角色完全保持@图片1设定图的形象（短腿Q版、南瓜橘+白围脖+白胸腹+没有尾巴、奶油脸、开心微笑表情）。姿态参照@图片2、@图片3、@图片4三张真实照片：狮身人面俯卧或侧躺放松，身体贴地，闭眼或困倦半眯眼，嘴里轻轻咬着一只翠绿色卡通鳄鱼玩具（咬在吻部，静态轻咬不咀嚼）。动画表现：缓慢自然的呼吸起伏（胸部一起一伏），偶尔眼睑微动、耳朵抖动，整体安静治愈的待机氛围。背景纯净浅色，无杂物，柔和暖光。适合循环播放的待机动画，5秒，画面稳定不抖动。
```

### 9.2 与五要素框架的映射

| 五要素 | 本 prompt 实现 | 关键差异 vs 失败轮 |
|--------|---------------|-------------------|
| ① 形象锚定 | @图片1 设定图 + 形象属性写进锚定（含**没有尾巴**）| **断尾是设定图的固有属性**，不是独立指令——v4/B 把"完全断尾"当文字指令，压不过参考图先验 |
| ② 体型约束 | 短腿Q版（设定图承载）| 不重复写数值，避免与设定图冲突 |
| ③ 特征细节 | 毛色全部交给设定图，文字**零毛色描述** | v3/v4 文字过度具象（"眉斑独立大块"）→ AI 照字面画成贴片 |
| ④ 动作描述 | 姿态借 @图片2/3/4 真实照片（**只借姿态不借毛色**）| v5/v6 用带缺陷的旧生成帧做参考 → 缺陷被复现（双头/尾巴）|
| ⑤ 画质参数 | 「适合循环播放」「画面稳定不抖动」| **显式压漂移**——v2-v6 隐性通病 |

### 9.3 六轮失败 → 成功的规律总结

| 轮次 | 参考图 | 关键错误 | 结果 |
|------|--------|---------|------|
| v1 | 设定图+3照片 | 无（但生成有尾巴）| 本体完美/有尾巴 |
| v2 | 设定图+3照片 | 横咬中段描述 → 对称双头 | 断尾/双头 |
| v3 | 设定图+3照片 | 文字过度具象毛色 | 单头/本体丑 |
| v5/v6 | v2帧（带双头）| 参考图带缺陷 → 复现 | 本体好/双头 |
| v4/B | V1帧（带尾巴）| 参考图带缺陷 → 复现 | 尾巴复现 |
| **成功** | 设定图+3真实照片 | 设定图锁形象+照片锁姿态+文字不越界 | **全过** |

**核心规律**：
1. 参考图**带什么缺陷就复现什么**——绝不用带缺陷的旧生成帧做参考
2. 断尾/毛色等身份属性**写进形象锚定**（随设定图走），不当独立文字指令
3. 真实照片**只借姿态**，毛色描述一律交给设定图
4. 文字**不越界描述细节**（越界 = AI 照字面画标准件）
5. 显式写「画面稳定不抖动」「适合循环播放」

### 9.4 复用模板（叮当后续动作直接套）

```
皮克斯3D动画风格。柯基角色完全保持@图片1设定图的形象（短腿Q版、南瓜橘+白围脖+白胸腹+没有尾巴、奶油脸、{表情}）。
姿态参照@图片2、@图片3、@图片4三张真实照片：{动作描述}。
动画表现：{动画表现}。背景纯净浅色，无杂物，柔和暖光。
适合循环播放的待机动画，5秒，画面稳定不抖动。
```

替换点：{表情} / {动作描述} / {动画表现}——其余（设定图锚定+照片锁姿态+稳定指令）不动。
