## 3. 专项验证

### 3.1 zip slip 集成验证（macOS / unzip 分支）

用 python zipfile 构造含 `../../escape-me.txt` 条目的恶意包（zip 命令会 sanitize `../`，真实攻击者用 zipfile）：

```
importPetZip 结果: {"ok":false,"error":"压缩包包含不安全路径条目，已拒绝（zip slip）：../../escape-me.txt"}
os.tmpdir 根下逃逸文件: ✅ 未逃逸
```

条目级拦截生效。Windows 分支（`tar -tf` 枚举）未真机验证——代码路径与 unzip 分支同构，待有 Windows 机器时补测。

### 3.2 纹理泄漏压测（Apple M5 Pro，统一内存架构）

100 次 `redshao` ↔ `pet2`（不同规格素材）切换，进程内存曲线：

| 指标 | 首 | 末 | 峰 | 后半 vs 前半 |
|------|-----|-----|-----|-------------|
| 渲染进程 workingSet | 483MB | 491MB | 503MB | Δ+3MB |
| GPU 进程 workingSet | 102MB | 103MB | 127MB | Δ+1MB |
| 主进程 RSS | 258MB | 238MB | 259MB | Δ−20MB |
| GPU 驱动 In-use system mem（ioreg） | 3398MB | 3231MB | 3409MB | 零增长 |

**结论：无泄漏曲线**——前 ~25 次为缓存建立期，之后全程平台期。`Texture.destroy()`（连 TextureSource）在 100 次尺度上有效，Assets cache 未造成可测泄漏。

限制：进程级 workingSet + ioreg GPU 驱动统计（统一内存架构下最接近「显存」的可观测指标），非显存仪表直接读数；样本 2 宠物 × 100 次 × 单机，3+ 宠物/高分屏待后续补充。

### 3.3 transitions 行为链实测

自然运行 10 分钟，hook `pet:action:notify` 收集 175 次动作切换：

- `sleep → stretch → idle` 链完整、按权重（sleep: stretch 80 / idle 20）正确转移，反复出现（10 分钟内 ≥20 次完整链）
- 切换间隔实测 2401-2403ms vs 理论 2400ms（12 帧 @ 5fps）——**误差 ±2ms**，frames/fps 即一轮精确时长，视觉无感
- 零跳变、零死锁（无 <2400ms 的异常打断）

**结论：时长估算方案满足产品预期，无需改用 AnimatedSprite.onComplete。**
