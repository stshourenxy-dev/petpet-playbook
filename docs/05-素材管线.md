# 05 · 素材管线：从一段视频到一张精灵表

> 本文档回答：AI 生成的宠物动作视频，如何变成桌宠可播放的精灵表。
> 核心结论：管线五步（抽帧→选帧→抠图→清理→拼表），每步工具可替换，参数基线成熟。

> **脚本位置**：④-⑧ 四步的可运行实现（参数化 CLI，无硬编码路径）在仓库 `pipeline/` 目录：`select_frames.py` / `remove_bg.py` / `clean_cutout.py` / `make_sheet.py`，依赖 Python + rembg + Pillow + numpy + scipy，跨平台。

---

## 1. 管线总览

```mermaid
graph LR
    A[AI 生成动作视频<br/>即梦/可灵] --> B[抽帧 ffmpeg<br/>fps=4 抽20帧]
    B --> C[选帧 select_frames<br/>去重精修选12帧]
    C --> D[抠图 rembg<br/>语义分割]
    D --> E[清理 clean_cutout<br/>去噪点]
    E --> F[拼表 make_sheet<br/>裁切对齐合成]
    F --> G[部署<br/>~/.petpet/pets/&lt;宠物名&gt;/]
    G --> H[重启桌宠生效]
```

| 步骤 | 脚本/工具 | 输入 → 输出 | 质量闸门 |
|------|----------|------------|---------|
| 抽帧 | ffmpeg | 视频 → 20 帧 PNG | fps=4（5 秒视频抽 20 帧） |

抽帧命令（视频在 `video.mp4`，输出到 `frames/`）：

```bash
mkdir -p frames && ffmpeg -i video.mp4 -vf "fps=4" -q:v 2 frames/f_%02d.png
```

> `fps=4` 从 5 秒视频抽 20 帧；`-q:v 2` 保画质（高码率 PNG 源对后续抠图更友好）。抽完用 `select_frames.py` 选帧。
| 选帧 | select_frames.py | 20 帧 → 12 帧 | 帧间差异度 0.04-0.12 为佳 |
| 抠图 | remove_bg.py（rembg） | 12 帧 → 透明底 | 白毛不被误删（语义分割优于色度） |
| 清理 | clean_cutout.py | 抠图帧 → 干净帧 | 只删 <500px 噪点，**不删连通域** |
| 拼表 | make_sheet.py | 12 帧 → 精灵表 | cell≤1024、总宽≤16384（WebGL 上限） |
| 部署 | 手动 | 精灵表 → 宠物包目录 | 替换同名文件 + 更新 pet.json |

## 2. 参数基线（实测成熟值）

| 参数 | 基线值 | 原因 |
|------|--------|------|
| 视频规格 | 1280×720、60fps、5 秒 | 即梦默认档，抽帧后 121 帧候选 |
| 抽帧密度 | fps=4（20 帧） | 5 秒覆盖全程，帧数够选 |
| 最终帧数 | 12 帧/动作 | 平滑度与文件体积平衡（12×1024=12288px） |
| 单元格 | ≤1024×1024 | 分辨率与纹理上限的平衡 |
| **总宽上限** | **≤16384px** | **WebGL 纹理硬上限（踩坑见 [07-踩坑实录](docs/07-踩坑实录.md)）** |
| 播放帧率 | fps=5 | 原速匹配：fps×帧数 ≈ 原视频 5 秒（决策链见 [06-参数详解](docs/06-参数详解.md) §3） |

## 3. 工具可替换矩阵（授人以渔核心）

每步都不是唯一解——按自己的环境替换：

| 步骤 | 本项目用 | 可替换为 | 替换注意 |
|------|---------|---------|---------|
| 视频生成 | 即梦 | 可灵/其他文生视频 | 输出要求：720P+、5 秒、主体全程入镜、背景干净纯色 |
| 抽帧 | ffmpeg | 任意视频工具 | 无 |
| 抠图 | rembg（语义分割） | 手动抠图/其他分割模型 | **语义分割优先**——色度抠图对白毛失效（白毛 vs 白底色差小，见 [07-踩坑实录](docs/07-踩坑实录.md)） |
| 清理 | 连通域分析 | 手工修图 | 默认只删微小噪点（<500px） |
| 拼表 | PIL | 任意图像库 | 遵守 cell 与总宽上限 |

## 4. 质量闸门：差异度量化

抽帧后先算**帧间差异度**（相邻帧像素差），用数据判断视频质量：

| 差异度 | 含义 | 判定 |
|--------|------|------|
| < 0.02 | 准静态（如深度睡眠） | 可做待机/睡觉，做动作则太平 |
| 0.04-0.12 | 正常动作（呼吸/摇摆/跑动） | ✅ 合格动作素材 |
| > 0.15 | 剧烈变化 | 选帧时优先保留动作峰值 |

首尾衔接差异度：< 0.05 循环播放不跳变（睡眠动画旧表 0.102 → 新表 0.021，换表硬理由）。

## 5. 横版素材的特殊处理（场景类动作）

16:9 横构图场景视频（狗+道具+床铺）无法塞进 1024×1024 正方形画布——切头切尾二选一。**方案：横版整帧**（完整场景、零伪影），代价是狗在窗口里变小约一半（权衡后接受）。

```
正方形画布（1024×1024）  ✗ 横场景必损（拉伸伪影/切头尾）
横版整帧（1024×576）    ✓ 完整场景、零伪影、狗变小
```

---

## 6. 本文档可自行修改的点

1. 帧数/分辨率按需调：帧数多=平滑但接近纹理上限；cell 大可=细节多但窗口适配变差
2. 工具矩阵按环境替换：有 GPU 工作站可上更大模型分割；纯手动修图也可（帧数少时可行）
3. 差异度阈值是经验值，按自己宠物的动作幅度微调
