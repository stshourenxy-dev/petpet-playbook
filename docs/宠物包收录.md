# 宠物包收录

> 用本 Playbook 做出来的宠物包，欢迎在这里登记——**只收链接，不收素材文件**（仓库体积红线，见 [CONTRIBUTING](../CONTRIBUTING.md)）。

**别人做成了，才证明方法论有效。** 你的宠物包就是最好的验证。

## 收录条件

1. 宠物包通过 `pipeline/validate_pet.py` 校验（`python pipeline/validate_pet.py <你的宠物包目录>`）
2. 素材是你自己生成/拥有的（不要放即梦生成的原版大视频，只放精灵表成品 + pet.json）
3. 提供可访问的链接（GitHub 仓库 / 网盘 / 其他），并注明动作数
